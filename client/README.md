# Rhythmic Beat Dance Court (RBDC) - Client Application

> **"Let ur body speak"** — A Yuvraaj's Dance School  
> Founded in 2004 by Artistic Director & Choreographer Master Yuvraaj Jayakumar.

A single-page, light studio home experience built with React, Vite, TypeScript, and Tailwind CSS.

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build
```

---

## ✏️ Editing Content & Data

All text, copy, styles, batches, and schedules live in `/src/data/*.ts`:
- `src/data/navigation.ts`: Header links and trial CTA
- `src/data/hero.ts`: Portal hero wordmarks and metadata
- `src/data/statement.ts`: Philosophy fold copy and orange accent text
- `src/data/styles.ts`: 6 confirmed dance disciplines and card details
- `src/data/roster.ts`: Cohorts, mentors, and age groups
- `src/data/schedule.ts`: Studio timetable rows
- `src/data/close.ts`: Official contact phone, WhatsApp, email, Instagram handle, and verified branch locations
